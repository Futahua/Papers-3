# Projects created for Papers use

This is the directory of independently maintained projects that the creator has made for
use with Papers.

A listing here records a real relationship and gives agents the correct project to pick
up. It does not make the project part of Papers' binary, define a plugin format, authorize
installation on another machine, or establish a common architecture for future projects.

## Adding another project

Add a project only after the creator has actually created or identified it for Papers use.
Record its purpose, canonical remote, known checkout where useful, ownership boundary and
machine/distribution status. Do not infer those facts from the first project or turn this
directory into a marketplace or product registry.
